# Regole Collection Content

## Description

- Minimo 150 caratteri testo per pillar collection
- Spiegare scope categoria con termini da title/handle
- Link interni ad articoli guida (quando presenti)

## Meta SEO

- seo_title: nome collection + brand/context shop
- seo_description: value proposition categoria, prodotti in evidenza (count reale se disponibile)

## Pillar content

- Collection con `products_count` alto = candidata guida/blog pillar
- Collection senza articoli collegati = opportunity `blog_topic` intent informational

## Miglioramenti

- Espandere description_html
- Aggiungere meta mancanti
- Collegare best seller della collection in contenuti editoriali
