# Regole Product Content

## Meta SEO

- Title: 50–60 caratteri ideali, minimo 30
- Description: 120–160 caratteri ideali, minimo 30
- Includere brand/product name da dati reali

## Body / description

- Descrizione prodotto utile per intent commerciale + informativo
- Evidenziare benefici da title, vendor, product_type (non inventare claim)
- FAQ prodotto quando obiezioni ricorrenti (issue `faq`)

## Priorità contenuto

1. Best seller con meta mancanti
2. Best seller con body debole (se disponibile in payload)
3. Prodotti ACTIVE con stock, zero vendite
4. Altri prodotti ACTIVE

## Miglioramenti suggeriti (non auto-applicati)

- Aggiungere meta title/description
- Espandere description con sezioni: features, use cases, sizing (se dati in variant/options)
- Link a articolo guida correlato quando esiste
